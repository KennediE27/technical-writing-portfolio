A new-operator guide based on publicly available Universal Robots documentation.

Audience

Deliverable
10-page quick-start guide

Project overview

This sample organizes technical and safety information into an operator-focused guide covering preparation, startup, robot initialization, basic operation, normal shutdown, troubleshooting, and technical specifications.

Documentation approach

The guide separates hardware from interface terminology, uses procedural steps for operator tasks, introduces safety information near the actions it affects, and includes tables, checklists, figures, and a troubleshooting section to support scanning and task completion.

Skills demonstrated

Technical research, user documentation, procedural writing, information architecture, safety communication, terminology management, tables and figures, troubleshooting content, and source-based documentation.
